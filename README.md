✊ Stone Paper Scissors Game
A classic Stone Paper Scissors game built using HTML, CSS, and JavaScript.
The player competes against the computer in a simple, interactive interface.

🛠️ Features
User vs Computer gameplay

Randomized computer choice

Score tracking

Result display (win, lose, draw)
